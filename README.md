# 도면편집기 (DraftDesk)

PDF·이미지 도면 위에 공조(네모)와 배관(직선·꺾기), 글씨를 그려 넣고 저장하는 웹 앱입니다.
공조 설치 기사님이 혼자서도 쓸 수 있도록 **큰 글씨, 큰 버튼, 적은 기능**을 목표로 만들었습니다.
파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 기능

- **도면 열기**: PDF(여러 장 가능), 이미지. 큰 버튼 또는 화면에 끌어다 놓기.
- **그리기**: 공조(네모), 배관(직선), 배관(꺾기, 방향 바꾸기 가능), 글씨. 기본 8색 팔레트.
- **글씨**: 입력한 말이 큰 버튼으로 쌓입니다(기본 13개 포함, 이 브라우저에만 저장).
- **수정·삭제**: 그린 것을 눌러 옮기기, 크기 조절, 색 바꾸기, 지우기(Delete 키 가능).
- **여러 장**: 페이지를 넘겨도 그린 내용이 유지됩니다.
- **확대**: 최대 400%, 마우스 휠 지원.
- **저장**: 전체 페이지 / 수정한 페이지만 / 지금 보는 한 장만. 한 장일 때만 PDF 또는 이미지(PNG) 선택.
  원본 이름 뒤에 `_편집`이 붙고 다운로드 폴더에 저장됩니다.
- 저장하지 않은 작업이 있는 채로 새 도면을 열거나 탭을 닫으려 하면 확인을 받습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 빌드
npm run deploy   # 빌드 후 GitHub Pages(gh-pages 브랜치)에 배포
```

## 기술

Vue 3 + Vite, [pdfjs-dist](https://github.com/mozilla/pdf.js)(보기), [pdf-lib](https://pdf-lib.js.org/)(저장), Vitest.
서버가 없으므로 GitHub Pages에 그대로 올라갑니다.

## 구조

- `src/lib/` — 화면과 무관한 로직(도형 기하, 저장 범위, 글씨 목록, PDF 내보내기)
- `src/composables/useDocument.js` — 열린 도면과 페이지별 도형 상태
- `src/components/` — 큰 버튼 UI와 도면 화면
- 설계 문서: `docs/superpowers/specs/`, 구현 계획: `docs/superpowers/plans/`

## 알려진 한계

- 저장된 PDF에서 **새로 쓴 글씨는 그림**으로 들어갑니다(선택·검색 불가). 원본 도면의 글씨는 그대로입니다.
- 글씨 목록·마지막 색은 그 브라우저에만 저장되어, 브라우저 기록을 지우면 사라집니다.
- 되돌리기(Undo), 임시 저장, PDF 합치기·분리는 없습니다.
